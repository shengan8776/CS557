## Final Project - Wave-Normal Tilted Duck on Gerstner Waves

### 🦆 Duck Tilting with Wave-Normal Alignment (Realistic Water Physics)

![Final Project Demo](ProjectFinal/demo.gif)

*Real-time Gerstner waves with a duck that tilts (pitch/roll) to the local wave normal, with dynamic lighting for depth.*

#### Key Features:
- **Realistic Wave Physics**: Gerstner wave equations with multiple wave components
- **Wave-Normal Alignment**: Duck tilts (pitch/roll) using the local wave normal for realistic orientation
- **3D Object Animation**: Duck responds dynamically to wave height and surface curvature
- **Real-time Parameter Control**: Interactive wave amplitude, frequency, and phase adjustment
- **Advanced Lighting**: Dynamic lighting with wave-normal perturbation
- **Multi-Shader Architecture**: Integrated multiple shader programs (duck rendering, wave effects)
